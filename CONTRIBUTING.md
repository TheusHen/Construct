# Contributing

Thanks for contributing to Construct.

## Development Setup

1. Install Java 21 or newer.
2. Clone the repository.
3. Build the project:

```bash
./gradlew build
```

## Guidelines

- Keep changes focused and small.
- Follow existing code style and package structure.
- Prefer clear names over clever code.
- Update docs when behavior or commands change.

## Commit Messages

Use clear, descriptive messages. Example:

```text
feat: add model selection setting in client config
```

## Pull Requests

Include:

- What changed
- Why it changed
- How it was tested
- Any known limitations
